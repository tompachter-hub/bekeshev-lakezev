# בקשב לקצב – השקפה

מאגר הידע של קהילת המורות במהלך השקפה. זה אתר סטטי (Astro). כל התוכן שמור בקבצי Markdown בתיקייה `src/content`, ואין צורך לגעת בקוד כדי להוסיף תוכן.

> הדרך הפשוטה ביותר: לפתוח את התיקייה ב-Claude Code ולבקש, למשל: "תוסיף את מפגש 3 מהצילומים האלה". ההסבר שלמטה מיועד למי שרוצה לעשות את זה ידנית או להבין מה קורה.

## מבנה התוכן

| תיקייה | מה יש בה | שם קובץ |
|---|---|---|
| `src/content/years/` | שנה (נושא שנתי) | `tashpaz.md` |
| `src/content/meetings/` | מפגש | `tashpaz-3.md` (שנה-מספר) |
| `src/content/items/` | פריט בארגז הכלים: מהלך, ריווח, מאמר, כלי, תוצר | שם קצר באנגלית, למשל `video-break.md` |
| `src/content/bots/` | בוט שנתי | `ritual.md` |
| `public/media/` | תמונות וקבצים להורדה | |

## הוספת מפגש חדש

יוצרים קובץ חדש ב-`src/content/meetings/`, למשל `tashpaz-3.md`:

```markdown
---
year: tashpaz
number: 3
date: 2026-11-30
title: "כותרת המפגש"
summary: "משפט אחד שמסכם את המפגש"
nextTask: "המשימה למפגש הבא"
photos:
  - src: "media/tashpaz-3-board.jpg"
    alt: "תיאור קצר של מה שרואים בתמונה"
whatsapp: "טקסט קצר לקבוצה (הקישור לדף מתווסף לבד)"
draft: false
---

## מהלך המפגש
...

## דילמות שעלו
(בניסוח כללי, בלי שמות ובלי פרטים מזהים)

## רעיונות מהמליאה
...
```

- המשימה של המפגש האחרון מוצגת אוטומטית בראש דף הבית.
- `draft: true` אומר שזו טיוטה: הדף מוצג רק בהרצה מקומית ולא באתר החי. כשהדף מאושר, משנים ל-`false`.

### כללי פרטיות (חובה)
- בלי שמות ותמונות של תלמידים.
- בלי שמות של מורות, אלא בהסכמה מפורשת.
- דילמות נכתבות בניסוח כללי, בלי פרט מזהה.
- לפני שמעלים תמונה של לוח או של דף, מטשטשים בה את השמות.
- חומרי מקור (צילומים מקוריים, הקלטות) שומרים בתיקייה `materials/`. התיקייה הזו לא עולה לאינטרנט.

## הוספת פריט לארגז הכלים

```markdown
---
title: "שם הפריט"
kind: "מהלך פדגוגי"     # אחד מ: מהלך פדגוגי, דילמה, רעיון מהמליאה, מאמר או מקור, קישור חיצוני, תוצר מורה, שיעור, כלי
year: tashpaz
meeting: tashpaz-2       # לא חובה: המפגש שבו הפריט עלה
ritualType: "סרטון"      # לא חובה: משחק, שיח, סרטון, בחירה לימודית, בחירה משחקית, חושית, עצירה וגמישות בזמן
summary: "משפט אחד"
url: ""                  # לקישורים ולמאמרים
whyRead: ""              # למאמרים: למה כדאי לקרוא
file: ""                 # לקובץ להורדה, למשל media/kalfei-siach.pdf
---

תיאור חופשי.
```

מאמר מקבל `kind: "מאמר או מקור"`, ומופיע אוטומטית גם בספריית ההעשרה.

## לוח מפגשים

מועדי המפגשים של השנה נמצאים בקובץ אחד: `src/content/schedule/tashpaz.md`. כל מפגש הוא שורת `date`, ואפשר להוסיף לו גם `time`, `place` ו-`topic`. הקובץ `_template.md` שבאותה תיקייה מראה את המבנה. המפגש הקרוב מוצג אוטומטית בדף הבית ובעמוד "לוח מפגשים".

## עבודת הסיכום השנתית

מעתיקים את `src/content/summaries/_template.md` לקובץ בשם השנה, למשל `tashpaz.md`. כותבים את הסיכום מתחת לקווים, ומשנים ל-`draft: false` כשהעבודה מוכנה לפרסום. אם יש קובץ PDF, שמים אותו ב-`public/media` וכותבים את הנתיב שלו ב-`file`.

## פרטי הקהילה

את השם, בית הספר, העיר, שם מובילת הקהילה ופסקת "על הקהילה" משנים בקובץ `src/site.config.ts`.

## הוספת שנה חדשה

1. יוצרים קובץ ב-`src/content/years/`, עם `current: true` ו-`order` גבוה יותר מהשנים הקודמות.
2. בשנה הקודמת משנים ל-`current: false`. היא תעבור אוטומטית לארכיון.

## הרצה מקומית

צריך להתקין [Node.js](https://nodejs.org) (גרסת LTS) פעם אחת. אחר כך, בתיקיית הפרויקט:

```
npm install
npm run dev
```

ופותחים את הכתובת שמופיעה במסוף.

## העלאת גרסה חדשה

האתר מתארח ב-GitHub Pages. כל שינוי שנשמר בענף `main` (commit + push) מתפרסם אוטומטית תוך כדקה, דרך הקובץ `.github/workflows/deploy.yml`. אם קובץ תוכן כתוב לא נכון (למשל `kind` שלא ברשימה), הבנייה תיכשל, ואז ב-GitHub, תחת הלשונית Actions, תופיע הודעה שמסבירה מה לתקן.

הגדרה חד-פעמית: ב-GitHub נכנסים ל-Settings → Pages ובוחרים ב-Source את האפשרות **GitHub Actions**. אחר כך מעדכנים את `site` ואת `base` בקובץ `astro.config.mjs`, כך שיתאימו לשם החשבון ולשם המאגר.

## שם האתר

את השם, תת-הכותרת והשורה התחתונה משנים בקובץ `src/site.config.ts`.
